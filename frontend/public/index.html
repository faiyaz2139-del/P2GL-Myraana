PRINT PRODUCTION STUDIO

From artwork to an approved proof, then to the press.

Myraana runs the path a print shop already knows: the file, the proof, and the press. Built inside Print2Go, a working print shop in London, Ontario.

How it works

  1. Specify the job. Size, stock, finish, sides, and quantity. A catalog preset fills the usual choice. A custom size is still a normal job.
  2. Check the artwork. Bleed, resolution, and colour are checked against the shop’s rules. A person approves the proof that matches the production file.
  3. Choose the route. Send the approved PDF to a verified press, or stop on a proof-only route when the shop is not ready to print.

Built inside Print2Go, a working print shop in London, Ontario.

Faiyaz runs the Print2Go shop at 201 Queens Ave and built Myraana on the jobs that shop prints. print2go.com is a shared site for the Ontario franchise. Myraana is the studio for this shop, and the product other shops can run for themselves.
